pamasahePH

Open index.html in any modern browser. No server, database or build tools required.

FIVE WEBPAGES:
index.html - EDSA Bus Carousel
mrt.html - MRT-3
lrt1.html - LRT-1
lrt2.html - LRT-2
routes.html - Routes & the uploaded fare matrices

Shared files: styles.css, fare-data.js, app.js. Keep all files and images together.

FARE DATA SOURCE:
EDSA: original supplied index.html September 28, 2026 matrix retained.
MRT-3: uploaded March 23, 2026 discounted 50% for all matrix.
LRT-1: April 2, 2025 Stored Value and Single Journey matrices, supplied by the user.
LRT-2: uploaded 2026 discounted 50% Stored Value matrix.

All rail fares are indexed from the supplied matrices, not fares estimated by station count.
No additional discounted fare is inferred for rail lines when a corresponding fare is not in the supplied images.
The original background image is an external URL and may be unavailable when offline.
